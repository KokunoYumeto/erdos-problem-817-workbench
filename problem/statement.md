# Erdős Problem 817, `k = 4` rate subproblem

For a finite set `A` of distinct positive integers, let

$$
H(A)=\left\{\sum_{a\in A}\varepsilon_a a:\varepsilon_a\in\{0,1\}\right\}.
$$

Let `g_k(n)` be the least `N` for which some `n`-element set `A ⊆ [N]` has
`H(A)` free of nonconstant `k`-term arithmetic progressions.

This workbench concerns the exact exponential rate when `k = 4`:

$$
\lim_{n\to\infty}g_4(n)^{1/n}.
$$

It does not redefine the broader problem, which asks for estimates for all
`k ≥ 3`. The historical `k = 3` lower-bound question is a separate subproblem;
Simone Costa answered it negatively in arXiv:2609.06303v1.
