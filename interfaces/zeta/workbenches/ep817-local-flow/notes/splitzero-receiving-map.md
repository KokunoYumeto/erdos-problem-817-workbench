## 4. The arithmetic map is a chain map of original paths

At general arity q>=2, put d=q-2. The overlap graph uses d-bit vertices and (d+1)-bit edges. Let D contain zero and satisfy

\[
D\subseteq[0,(q-1)(b-1)].
\]

This includes actual higher-arity digits exceeding the base. For an input edge a=(a_0,...,a_d), its b output edges have bits

\[
o_r^{(z)}=\bigvee_{0\le h\le d,\ bh+z\in D+r}a_h,
\quad 0\le z<b,\quad0\le r\le d.
\]

The corresponding vertex map is

\[
\phi(s)_r=\bigvee_{1\le h\le d,\ bh-1\in D+r}s_{h-1}.
\]

The range bound accounts for every possible h. Direct comparison of adjacent bits shows that these output edges form a path from phi(source(a)) to phi(target(a)). Let L be the resulting edge-path matrix and V the vertex map matrix. Then

\[
\boxed{\partial L=V\partial.}
\]

\[
\boxed{c(D+bY)=Lc(Y)-g e_0,\qquad
