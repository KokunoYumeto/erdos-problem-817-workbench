# Bounded public-artifact check

The public repository
[`mehmetmars7/Erdosproblems-llm-hunter`](https://github.com/mehmetmars7/Erdosproblems-llm-hunter)
contains one file for Problem 817 at
`attacks/erdos/gpt_pro_5.2/817.tex`. It was introduced in commit
`8dc65cf1fc41f447a2cc90a04876e50b650473d1` on 17 January 2026 and received a
one-comment-line cleanup in commit
`2863625169a603a97c8e5cfc89aaf84fefc20c6a` later that day.

That artifact proves the standard base-3 upper construction for the `k = 3`
case, records small computed values, and labels its attack unresolved. It does
not contain the relation-splitting theorem, the `{1,7,8}` block, the mod-19
digit set, the base-19 lifting, or the exact `19^(1/3)` rate. It is therefore a
different attack, not a public antecedent of the proof reconstructed here.

This is a bounded repository check, not a novelty or priority determination.
