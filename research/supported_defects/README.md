# Supported defect classes and infinite obstruction control

This additive EP817 continuation studies the original arithmetic actions of
retained zero-boundary classes, rather than discarding those supports. It gives
a complete relative-cohomology description of separated deformations of the
nineteen-adic construction, and an exact all-graph visibility filtration.
All new theorems have ordinary written proofs and exact bounded computational
checks. Independent mathematical review is pending; no new Lean check or
literature-priority claim is made.

The main theorem permits arbitrary signed perturbations of all three generators
in each of r original blocks. The retained class is d_j=p_j+q_j-s_j in the
literal relative H^1 of the path graph. For every k>=4, the perturbed image is
k-free exactly when the indexed binary defect image is k-free. Both witness
maps, all values, multiplicities and quotient metrics are explicit. The
separation parameter and its cost remain in the statement.

A common terminal perturbation activates an (r+1)-term progression at every
rank. Its supported specialization class and first derivative are calculated.
The all-graph theorem computes every integral source direction module through
the original cut capacities and the image ideal of its mark observation.
Identifying equally marked vertices is also treated through an edge-preserving
quotient and its full relative cycle sequence.

## Reproduction

From this directory, run `python run_checks.py`. The program reruns all four
standalone producers/auditors into a temporary directory and requires bytewise
agreement with the stored records. `python run_checks.py --optimized` repeats
the same checks under Python -O. No package outside Python's standard library
is required, and no inherited verification receipt is overwritten.

The main suite covers the stated finite deformation domains and all labelled
simple graphs through five vertices, with full compressed proof data. The
second suite tests the observation-faithful quotient on 1,211 marked graphs,
60,585 original masks, and twelve complete relative theta incidences. See
`polyclank/verification.json` for all exact domains and replay records.
